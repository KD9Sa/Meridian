How to read this report +

A consistent snapshot. This demonstration uses a fixed June 2026 dataset for Acme Studio, with all amounts in USD. Revenue includes captured payments. Transaction counts include completed, pending and failed attempts; revenue per transaction is captured revenue divided by all initiated transactions.

Rounded for readability. Percentage changes are calculated from source values and rounded. The May average is $88.65 before presentation rounding; the June decrease is approximately 2.3%. Channel shares are rounded, with dollar values balanced to the $128,430 total. Funnel data uses unique sessions and is a separate cohort from transaction attempts.

Monthly chart data. January $82,400; February $89,300; March $87,100; April $105,200; May $113,655; June $128,430. Q1 totals $258,800 and Q2 totals $347,285. Interval controls change the chart presentation locally; this report does not retrieve live data.
